# Controle Remoto
<!-- impeccable:product-schema 1 -->
## Platform
web, mobile primeiro, instalável como PWA. Usuário solicitou publicação no GitHub como os outros projetos e uso pela Tela de Início do iPhone.
## Stack
React, Vite, JavaScript, CSS, Lucide, Node.js conforme solicitação.
## Produto
Controle doméstico pelo Wi-Fi com descoberta, conexão manual, reconexão e demonstração explicitamente identificada. Interface escura minimalista inspirada no acabamento nativo Apple. Botões confortáveis e tela principal compacta.
## Escopo técnico da primeira versão
Roku ECP escolhido por documentação pública. Usuário informou Samsung UN60DU7700GXZD (DU7700 2024). Adaptador Samsung Tizen v2 implementado com pareamento autorizado na TV. LG e Android TV não estão implementados. Validação física permanece pendente até haver TV disponível.

O usuário confirmou funcionamento físico na Samsung. A nova instalação no iPhone continua pendente de teste no aparelho. Publicação: GitHub Pages em `Davvi0/remote-do-davisao`, branch main, pasta docs. Controle real mantém servidor Node local; versão publicada oferece configuração HTTPS do servidor com origem autorizada, nunca promete acesso direto à TV pela nuvem.
